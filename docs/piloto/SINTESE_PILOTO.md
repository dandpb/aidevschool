## Gate de saída do piloto

Marque exatamente um:

- [ ] **Verde — promessa observada neste recorte.**
- [ ] **Amarelo — evidência inconclusiva.**
- [ ] **Vermelho — promessa falhou ou há defeito bloqueante.**

**Justificativa baseada nas seis promessas**

> _Preencher._

**Lacunas que impedem uma conclusão diferente**

- _Preencher._

**Próxima ação autorizada**

- [ ] Nova rodada pequena para cobrir lacuna.
- [ ] Correção e revalidação de defeito.
- [ ] Revisão humana do kit/evidência.
- [ ] Nenhuma; encerrar este recorte.

Não registrar “lançar”, “escalar mercado” ou “domínio comprovado” como consequência automática de
um gate verde.
