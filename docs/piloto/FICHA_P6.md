# Ficha de observação P6 — piloto com alunos reais (checklist objetivo)

Uma cópia por participante, preenchida fora do repositório. Somente códigos
`P01`–`P03`; sem nome, contato, IP, identificador ou conteúdo de tarefa real.
Antes de anexar a uma issue autorizada, passe a revisão de privacidade do
[kit AID-639](../PILOTO_PERCURSO_CLIENTE.md#3-consentimento-e-privacidade).

Esta ficha captura **apenas o que gateia O3-C2** (bloqueio de entrada, tempo
até a primeira conclusão, compreensão do resultado local, ritmo diário). O
protocolo de 3 sessões completo — com recuperação, transferência e as seis
promessas — continua na
[FOLHA_OBSERVACAO](FOLHA_OBSERVACAO.md) do kit AID-639; se você usou as três
sessões, preencha as duas e anexe as duas. Contagens sempre com denominador
(`2/3`), nunca percentual.
