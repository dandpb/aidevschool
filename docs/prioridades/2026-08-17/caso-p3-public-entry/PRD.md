# PRD — Entrada pública encontrável para a trilha IA Prática

## Problema

O README raiz diz que ainda não existe uma rota pública browser-only, mas a visão do produto
registra uma URL pública do LiteracyDojo e a URL responde HTTP 200. A pessoa que clona ou visita
o repositório recebe uma instrução contraditória.

## Usuário

Um aluno, facilitador ou contribuidor que procura o primeiro produto utilizável.

## Objetivo

Deixar o README coerente com a rota pública verificada, sem transformar o README em status de
mastery ou prometer uma trilha Dev que ainda é preview.

## Escopo

- indicar o LiteracyDojo público como entrada da trilha IA Prática;
- manter explícito que o progresso é local e sem conta;
- manter a trilha Dev separada e sem promessa de prontidão;
- criar um verificador textual pequeno para impedir o retorno da frase stale.

## Fora de escopo

- mudar a aplicação;
- criar analytics;
- publicar nova versão;
- garantir retenção ou aprendizagem de uma pessoa real;
- declarar que a trilha Dev está pronta.

## Critérios de aceite

- [x] O README contém a URL pública da trilha IA Prática.
- [x] O README não afirma que não há rota browser-only.
- [x] A URL pública responde HTTP 200 nesta rodada.
- [x] A trilha Dev continua marcada como caminho distinto.
