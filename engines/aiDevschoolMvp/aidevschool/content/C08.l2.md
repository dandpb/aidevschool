## Hook
If chatting does not restart the whole practice phase, what *are* you doing each time you type
a question — and what already happened long before you opened the app?

## Worked example
Practice is the heavy phase that tunes internal dials on many examples. Everyday use is
the light phase: the AI produces an answer from know-how it already has. Builders run
practice. You mostly run use. Mixing the two leads to false hopes, like thinking one
clever message rewrote the entire system, or thinking a bad chat answer means nobody
ever practiced.

## Practice
Level 2 — write three short labels for a timeline: one for big practice, one for optional
extra practice on a narrow topic, and one for a normal user question. One line each.

## Gate task
The tutor will send you three short questions, one at a time or together. Answer each
with A, B, or C.
## Reply format
Reply with just the three letters in order, like: A C B.
## Feedback snippets
- On pass: "You separated the factory from the storefront. Practice builds; use serves.
  That clarity stops a lot of AI myths."
- On fail: "Ask which timeline you are in: long practice that tunes dials, or quick use
  that only produces an answer."
