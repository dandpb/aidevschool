# 🛤️ Trilha 02 — Programação, Algoritmos & Python

> **Fase do board:** F1 — Fundamentos (estágios 1–2) · **Duração:** 8–12 semanas · **Pré-requisito:** Trilha 01

## 🎯 Objetivo

Sair de zero em programação: lógica, algoritmos, estruturas de dados, paradigmas —
usando Python (CS50P) como linguagem principal e C (CS50x) para entender a máquina.
Atende o estágio 2 do board: "Escolha uma linguagem".

## 📦 Módulos

### M1 — Lógica de programação com Python (4–6 semanas)

- ✅ [CS50P — Introduction to Programming with Python](https://cs50.harvard.edu/python/)
  — de variáveis a orientação a objetos. Curso oficial Harvard, gratuito, com psets.
- Estruturas de dados cobertas no board: listas, dicionários, conjuntos, tuplas.

**Checkpoint:** psets das weeks 0–4 do CS50P (funções, loops, exceções).

### M2 — Algoritmos e estruturas de dados (3–4 semanas)

- ✅ [CS50x 2026](https://cs50.harvard.edu/x/) — Weeks 3–6: Algorithms, Memory,
  Data Structures, Python. (Continuação da Trilha 01.)
- Foco: complexidade Big-O na intuição, busca linear/binária, ordenação,
  listas encadeadas, hash tables, árvores, tries.

**Checkpoint:** implementar em Python: busca binária, bubble/merge sort,
lista encadeada e hash table — cada uma com teste simples.

### M3 — Paradigmas de programação (1 semana)

- Tópico do board: **Paradigmas** (imperativo, orientação a objetos, funcional).
- Leitura: comparar como Python trata os três paradigmas (classes, funções de
  primeira classe, comprehensions).

**Checkpoint:** resolver o mesmo problema 3× (procedural, OO, funcional) e
escrever 1 parágrafo comparando.

## 🛠️ Projeto prático

**CLI de biblioteca** (ecossistema do caso de estudo): cadastro de livros, empréstimos
e multas, persistindo em JSON. Usar funções, classes, exceções e testes simples `assert`.

## 🏁 Critérios de conclusão

- [ ] CS50P finalizado (psets + final project enviado).
- [ ] CS50x Weeks 3–6 concluídas.
- [ ] 4 estruturas de dados implementadas do zero com testes.
- [ ] CLI de biblioteca funcional em repo Git (com `README.md` de uso).
