# 🛤️ Trilha 01 — Fundamentos de Computação & Linux

> **Fase do board:** F1 — Fundamentos (estágios 1) · **Duração:** 4–6 semanas · **Pré-requisito:** nenhum

## 🎯 Objetivo

Entender como um computador executa programas — hardware, memória, CPU, sistemas
operacionais — e dominar o uso diário do Linux via terminal. É a base obrigatória
antes de qualquer especialização.

## 📦 Módulos

### M1 — Como o computador funciona (1 semana)

- ✅ [CS50's Understanding Technology — Week 1: Hardware](https://cs50.harvard.edu/technology/2017/weeks/1/)
  — hardware, bits, como a máquina processa informação.
- Tópicos do board: como programas rodam na memória; como os processadores funcionam;
  diferença entre linguagem compilada × interpretada.

**Checkpoint:** escrever com suas palavras (meia página) o caminho de um programa
desde o código-fonte até a CPU, citando memória RAM, compilador/interpretador e SO.

### M2 — Linux do zero (2–3 semanas)

- ✅ [Curso de Linux — Primeiros Passos (Curso em Vídeo, Gustavo Guanabara)](https://www.youtube.com/playlist?list=PLHz_AreHm4dlIXleu20uwPWFOSswqLYbV)
  — playlist completa (o board linka o [trailer](https://youtu.be/6nN2EglOqCM)).
- ⚠️ [Linux Command Cheat Sheet — 100 comandos essenciais](https://medium.com/@prateek.malhotra004/linux-command-cheat-sheet-100-essential-commands-for-system-administration-and-development-6ee91049d71a) — referência rápida.

**Prática:** instalar Ubuntu ou Debian (dual-boot ou VM) e usá-lo como ambiente
de estudo dali em diante. Navegação (`cd/ls/mkdir`), arquivos (`cat/less/cp/mv`),
permissões (`chmod/chown`), processos (`ps/kill/top`), pipes e redirecionamento.

**Checkpoint:** fazer todo o fluxo "criar projeto → editar arquivo → executar script →
ler log" 100% pelo terminal, sem gerenciador de arquivos.

### M3 — CS50x: as primeiras semanas (1–2 semanas)

- ✅ [CS50x 2026](https://cs50.harvard.edu/x/) — Weeks 0–2 (Scratch, C, Arrays).
  O board chama de "a base sólida"; este módulo cobre pensamento computacional prático.

**Checkpoint:** completar os problem sets das Weeks 0–1.

## 🛠️ Projeto prático

Um "diário de instalação": repositório Git com anotações datadas de cada comando
aprendido, problemas encontrados no Linux e como resolveu.

## 🏁 Critérios de conclusão

- [ ] Explicar compilado × interpretado com um exemplo de cada.
- [ ] Demonstrar 20 comandos Linux de memória (navegação, arquivos, permissões, processos).
- [ ] CS50x Weeks 0–1 concluídas com psets enviados.
- [ ] Diário de instalação com ≥ 10 entradas.
