## 📚 Cursos do CS50 (Harvard)

A série CS50 do Harvard é a base recomendada para programação e ciência da computação:

### 1. CS50P — CS50's Introduction to Programming with Python
   - **Link:** [cs50.harvard.edu/python/](https://cs50.harvard.edu/python/)
   - **Descrição:** Curso introdutório de Python. Ideal para iniciantes. Cobre desde variáveis até orientação a objetos.

### 2. CS50x 2025
   - **Link:** [cs50.harvard.edu/x/](https://cs50.harvard.edu/x/)
   - **Descrição:** Harvard CS50 — o curso mais famoso de introdução à ciência da computação. Cobre pensamento computacional, algoritmos, estruturas de dados, e linguagens.

### 3. CS50's Introduction to Databases with SQL
   - **Link:** [cs50.harvard.edu/sql/](https://cs50.harvard.edu/sql/)
   - **Descrição:** Curso focado em bancos de dados e SQL. Cobre modelagem, queries, joins, transações.

### 4. Week 1: Hardware / CS50's Understanding Technology
   - **Link:** [cs50.harvard.edu/technology/2017/weeks/1/](https://cs50.harvard.edu/technology/2017/weeks/1/)
   - **Descrição:** Como o computador funciona por dentro — hardware, bits, redes.

### 5. Week 2: Programming Languages / CS50's Understanding Technology
   - **Link:** [cs50.harvard.edu/technology/2017/weeks/2/](https://cs50.harvard.edu/technology/2017/weeks/2/)
   - **Descrição:** Como linguagens de programação funcionam — compilação, interpretação, paradigmas.

### 6. Week 4: Security / CS50's Understanding Technology
   - **Link:** [cs50.harvard.edu/technology/2017/weeks/4/](https://cs50.harvard.edu/technology/2017/weeks/4/)
   - **Descrição:** Fundamentos de segurança — criptografia, ataques, defesa.

### 7. Week 5: Web Development / CS50's Understanding Technology
   - **Link:** [cs50.harvard.edu/technology/2017/weeks/5/](https://cs50.harvard.edu/technology/2017/weeks/5/)
   - **Descrição:** Como a web funciona — HTML, CSS, JavaScript, requisições HTTP.

### 8. CS50's Web Programming with Python and JavaScript
   - **Link:** [cs50.harvard.edu/web/](https://cs50.harvard.edu/web/)
   - **Descrição:** Curso completo de desenvolvimento web full-stack com Python/Flask e JavaScript.

### 9. SQLBolt — Learn SQL — Lesson 1: SELECT queries 101
   - **Link:** [sqlbolt.com/lesson/select_queries_introduction](https://sqlbolt.com/lesson/select_queries_introduction)
   - **Descrição:** Tutorial interativo para aprender SQL fazendo exercícios práticos.

### 10. Curso de Linux — Primeiros Passos
   - **Link:** [youtube.com/playlist?list=PLHz_AreHm4dlIXleu20uwPWFOSswqLYbV](https://youtube.com/playlist?list=PLHz_AreHm4dlIXleu20uwPWFOSswqLYbV)
   - **Descrição:** Playlist do Curso em Vídeo (Gustavo Guanabara) sobre Linux, do básico ao avançado.

## 📊 Resumo dos Treinamentos

| Curso | Foco | Dificuldade |
|---|---|---|
| CS50x 2025 | Ciência da computação geral | Iniciante |
| CS50P | Programação Python | Iniciante |
| CS50 SQL | Bancos de dados SQL | Iniciante-Intermediário |
| CS50 Understanding Technology | Como funciona o computador/web/segurança | Iniciante |

## 💡 Ordem Sugerida de Estudos

1. **CS50x 2025** (base sólida)
2. **CS50P** (Python prático)
3. **CS50 SQL** (bancos)
4. **CS50 Understanding Technology** (séries de 1 semana cada)
5. **CS50 Web** (projetos práticos)
6. **SQLBolt** (prática SQL)
7. **Curso de Linux** (Linux)

Esses cursos cobrem **toda a Fase 1 (Fundamentos)** e boa parte da Fase 2 (Dados).
