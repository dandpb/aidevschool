## ☁️ Certificações AWS

As certificações AWS recomendadas para arquitetos (com links oficiais):

1. **[AWS Certified Solutions Architect — Associate](https://aws.amazon.com/pt/certification/certified-solutions-architect-associate/)** — Nível Associate — fundamentos de arquitetura AWS. Recomendado como ponto de partida.
2. **[AWS Certified Solutions Architect — Professional](https://aws.amazon.com/pt/certification/certified-solutions-architect-professional/)** — Nível Professional — arquitetura avançada, migração, multi-account, hybrid.
3. **[AWS — Recursos para arquitetos](https://aws.amazon.com/pt/training/learn-about/architect/)** — Página oficial de treinamento AWS para arquitetos.
4. **[AWS Certified Solutions Architect — Associate (Exam Guide PDF)](https://d1.awsstatic.com/onedam/marketing-channels/website/aws/en_US/certification/approved/pdfs/docs-sa-assoc/AWS-Certified-Solutions-Architect-Associate_Exam-Guide.pdf)** — Guia oficial de preparação para o exame Associate.
5. **[AWS Certified Solutions Architect — Professional (Exam Guide PDF)](https://d1.awsstatic.com/pt_BR/training-and-certification/docs-sa-pro/AWS-Certified-Solutions-Architect-Professional_Exam-Guide.pdf)** — Guia oficial de preparação para o exame Professional.

## 🏗️ Recursos de System Design

Recursos visuais e cursos para dominar System Design:

1. **[ByteByteGo — System Design Interview Course](https://bytebytego.com/?fpr=renato-augusto10)** — Curso visual completo de System Design por Alex Xu (autor do livro System Design Interview). Inclui padrões, escalabilidade, sharding, caching.
2. **[System Design Interview (livro)](https://amzn.to/3FzR4z5)** — O livro original com 16 problemas clássicos de system design.
3. **[Blog ByteByteGo](https://blog.bytebytego.com/)** — Posts regulares com diagramas explicativos de system design.
