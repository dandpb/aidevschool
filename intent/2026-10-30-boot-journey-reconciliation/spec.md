# Specification

If an initial deep-link journey switch fails, reread the authoritative progress without retrying the switch. On a valid reread, use that progress for boot and show a concise uncertainty notice; if reread cannot confirm state, stop on recovery with a reload action. Preserve normal switching, destination, saved progress and hosted behavior. Verify pre-write and post-commit failures, read failure, no repeated writes, normal link and independent browser review.
