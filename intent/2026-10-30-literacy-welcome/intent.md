# Intent: make the first learning journey understandable

A new learner encounters a long welcome page and, on a 375×812 viewport, must scroll past artwork before reaching the start action. Make the first steps tangible and the start action easier to find while preserving informed pilot consent, the developer route, and the existing onboarding and learning-state boundaries. The user authorized a bold UX improvement and requested real iterative verification; no conversion outcome is assumed.
