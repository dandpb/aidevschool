# Spec: kit de copy O1 (PT-BR)

Change-id: AID-2702-o1-outreach-copy · From: intent/AID-2702-o1-outreach-copy/intent.md · Status: accepted

## Requisitos

1. Arquivo único `work-products/AID-2702_O1_OUTREACH_COPY_PTBR_2026-09-26.md`.
2. Seções obrigatórias: `## Mensagem — DM WhatsApp`, `## Mensagem — LinkedIn`,
   `## Mensagem — comunidade Discord`, `## Hero (proposta)`,
   `## Guardrails`.
3. Cada mensagem: PT-BR, ≤ 480 caracteres (canal de DM), voz do produto
   (lições curtas, ritmo de Duolingo), sem jargão de engenharia para o
   caminho não-engenheiro.
4. Hero: headline + subhead para o caminho não-engenheiro leve ("usar IA sem
   programar") + variante dev.
5. Guardrails: sem promessas além do roteiro; sem incentivo financeiro;
   consentimento escrito; contato só em armazenamento restrito de pesquisa.
6. Sem PII real; placeholders apenas.

## Checks executáveis

- C1 (standard): arquivo existe, seções obrigatórias presentes, tamanho
  total plausível (> 500 chars, < 8000 chars).
- C2 (cheap): sem padrão de e-mail ou telefone no arquivo.
- C3 (cheap): sem vocabulário de incentivo/promessa proibida.
